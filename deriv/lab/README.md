# 콜 우위 가설 연구소 (deriv/lab)

사용자 가설: 코스피200 옵션에서 콜 행사가·물량이 압도적으로 우세하면, 단기든 장기든 외국인은 지수를 그 행사가 위로 만든 뒤 매도를 이어간다.
목표: 이 가설이 왜 지금까지 확률이 낮게 나왔는지 찾고, 방향(추세·급락·급등)을 **80% 이상** 맞히는 신호를 찾아 매매 포지션(선물·옵션·ETF) 판단에 쓰는 것.
멈춤: 아래 '통과' 기준을 모두 만족하는 후보가 나오면 멈추고 보고. 그 전까지 라운드마다 보고.

## 고정 규칙(총괄도 바꾸지 않음)

- 개발 구간 2015~2023(가격·수급 지표는 2010~), 잠금 구간 2024-01-01~현재. 탐색·문턱은 개발 구간에서만.
- 잠금 구간 결과는 A8 만 계산하고, 열 때마다 원장(state/ledger.json)에 횟수를 누적. 통과 p 기준 = 0.05 ÷ 누적 열람 횟수.
- 신호는 그날 장 마감 뒤 아는 값만 쓰고, 다음 거래일 시가 진입. 겹치는 거래는 버리고 독립 거래만 센다.
- 통과(모두 만족):
  1. 개발: 독립 거래 ≥ 20, 적중 ≥ 75%, 윌슨 90% 하한 ≥ 60%, 그 방향의 기본 확률 ≤ 60%, 거래 있는 해의 과반에서 적중 ≥ 70%
  2. 잠금: 독립 거래 ≥ 12, 적중 ≥ 80%, 기본 대비 이항 p < 0.05 ÷ 누적 열람
  3. 반증: 시점 이동 위약 p < 0.05, 한 해 빼기 최저 ≥ 70%, 한 해 쏠림 < 40%
- A8 의 기준값·구간·원장은 고치지 않는다. 고치면 그 라운드는 무효.

## 검증 방식 바뀜 — 2026-11-21(KST)부터 잠금 규칙 없이 양방향 교차 검증(사용자 지시 2026-11-20)

> "오늘까지는 잠금 구간 규칙을 그대로 두고 내일부터는 잠금 구간 규칙을 제거해 반대로 교차 검증도 실시하고 단시간 단기간 장기간 모든 가능성을 열어두고 검증"

- 2026-11-20 까지: 위 고정 규칙 그대로(잠금 구간 2024~ 는 A8 만, 열람 누적).
- 2026-11-21 부터(A8 이 날짜로 자동 전환, round.json 의 a08.cv_mode 'holdout'·'cross' 로 강제 가능):
  - 탐색은 전 기간(2010~현재) 어디서나 해도 된다. 잠금 열람 횟수는 더 쌓지 않는다(ledger.cross_tests 를 센다).
  - 앞 구간 P1 = 2010~2023, 뒤 구간 P2 = 2024~현재.
  - 앞→뒤: P1 에서 위 '개발' 기준으로 선별 → P2 에서 확인(독립 거래 ≥ 12, 적중 ≥ 80%, 기본 대비 이항 p < 0.05 ÷ 이 라운드 앞→뒤 선별 수).
  - 뒤→앞(반대 교차 검증): P2 에서 선별(독립 거래 ≥ 12, 적중 ≥ 75%, 하한 ≥ 60%, 기본 ≤ 60%, 거래 있는 해 과반 적중 ≥ 70%) → P1 에서 같은 확인(÷ 뒤→앞 선별 수).
  - 목표 판정 = 두 방향 모두 통과(+ A10 반증 '버팀', 전 기간·앞 구간은 해마다 고른 신호로). 한 방향만 통과는 따로 보고한다.
  - 기간은 모두 연다: 단시간(다음 날 시가→종가 = 보유 1일), 단기(2·3·5일), 중기(10·20일), 장기(40·60·120일), 큰 변동 창(5~60일).
    장기 보유는 뒤 구간(약 3년)에서 독립 거래가 12개를 넘기 어렵다 — 그 경우 '뒤 구간 표본 부족'으로 보고한다.
  - 앞 구간에서 문턱·조합을 정한 에이전트(A5 분위, A6 조합, A7 학습)는 뒤→앞 방향이 공정하도록 뒤 구간에서 다시 정하는 변형(fit_period)을 총괄이 더한다.
  - 그대로인 것: 원자료를 추정으로 채우지 않음, 표본 10개 미만을 '80%'로 보고하지 않음, 신호는 그날 장 마감 뒤 아는 값만·다음 날 시가 진입·독립 거래만.
