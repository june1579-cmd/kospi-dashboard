# 콜 우위 가설 연구소 (deriv/lab)

사용자 가설: 코스피200 옵션에서 콜 행사가·물량이 압도적으로 우세하면, 단기든 장기든 외국인은 지수를 그 행사가 위로 만든 뒤 매도를 이어간다.
목표: 이 가설이 왜 지금까지 확률이 낮게 나왔는지 찾고, 방향(추세·급락·급등)을 **80% 이상** 맞히는 신호를 찾아 매매 포지션(선물·옵션·ETF) 판단에 쓰는 것.
멈춤: 아래 '통과' 기준을 모두 만족하는 후보가 나오면 멈추고 보고. 그 전까지 라운드마다 보고.

## 고정 규칙(총괄도 바꾸지 않음)

- 개발 구간 2015~2023(가격·수급 지표는 2010~), 잠금 구간 2024-01-01~현재. 탐색·문턱은 개발 구간에서만.
- 잠금 구간 결과는 A8 만 계산하고, 열 때마다 원장(state/ledger.json)에 횟수를 누적. 통과 p 기준 = 0.05 ÷ 누적 열람 횟수.
- 신호는 그날 장 마감 뒤 아는 값만 쓰고, 다음 거래일 시가 진입. 겹치는 거래는 버리고 독립 거래만 센다.
- 통과(모두 만족):
  1. 개발: 독립 거래 ≥ 20, 적중 ≥ 75%, 윌슨 90% 하한 ≥ 60%, 그 방향의 기본 확률 ≤ 60%, 거래 있는 해의 과반에서 적중 ≥ 70%
  2. 잠금: 독립 거래 ≥ 12, 적중 ≥ 80%, 기본 대비 이항 p < 0.05 ÷ 누적 열람
  3. 반증: 시점 이동 위약 p < 0.05, 한 해 빼기 최저 ≥ 70%, 한 해 쏠림 < 40%
- A8 의 기준값·구간·원장은 고치지 않는다. 고치면 그 라운드는 무효.

## 알림(카카오톡)

총괄이 라운드마다 `deriv/lab/notify/kakao.txt`(===== 로 나눈 한 통마다 200자 이내)를 고쳐 push 하면 `deriv-notify` 워크플로가 카카오톡 '나에게 보내기'로 보낸다(대시보드와 같은 비밀값, 토큰은 읽기만, main 은 쓰지 않음).
결과는 `deriv/lab/notify/last.json`(sent·deferred·failed). 대시보드 토큰이 연장될 수 있는 기간에는 보류(deferred)되므로 그때 총괄은 휴대폰 알림으로 대신 보낸다.

## 라운드 돌리기

`deriv/lab/round.json` 의 round 를 1 올리고 계획(note)·에이전트 설정을 바꿔 push → GitHub Actions `deriv-lab` 이 A2→(A3~A7 동시)→A8→A9→A10→정리 순서로 돌고 `deriv/lab/out/round_NNN/` 과 `state/` 를 커밋한다.
보고: `out/round_NNN/report.md`, 순위표 `leaderboard.csv`, 상태 `status.json`, 누적 `state/history.md`.
