# T2 상태 → 방아쇠 — 미리 정한 시험 목록 (2026-11-24 작성, 돌린 뒤 고치지 않음)

## 0. 무엇을 보나
앞선 조사(deriv/turn)에서 '바닥 전 상태' 지표만으로 만든 신호는 약했다(바닥보다 먼저 켜지고 더 내림).
T2 는 **상태가 켜진 구간 안에서 방아쇠(돌아서는 표시)가 나온 날만** 매수 신호로 삼으면 나아지는지 본다. 오름(+1) 방향만.
상태가 보태는 몫을 가르려고 '상태만(방아쇠 없음)'과 '방아쇠만(상태 없음)'을 나란히 채점한다.

- 자료: `sa_common.Data()` 의 D.X(지표 434개), D.K(코스피 지수 시고저종). 가격은 전부 코스피 지수.
- 기호: c = 종가, o = 시가, h = 고가, l = 저가, r[t] = c[t]/c[t−1] − 1.
  자리(X)[t] = X 의 t일 값이 '그날까지의 지난 250거래일(최소 120일)' 가운데 몇 번째인가(0~100, rolling 순위). 전체 기간 순위는 쓰지 않는다.
  σ[t] = r[t−60] … r[t−1] 의 표준편차(그날 '직전' 60일, 당일 제외. 60일이 다 있어야 값이 있음).

## 1. 상태 (해마다 그 해 이전 자료로 다시 고름 — deriv/turn/turn_signal.py 의 build() 와 같은 방식)
해 Y(2016~2026)마다 cut = Y년 첫 거래일. **cut 앞 자료만** 쓴다.
1. 전환 저점: 코스피 종가 c[:cut] 에 zigzag 5% (저점에서 5% 이상 오르면 그 저점이 '저점'). cut 전에 **확정된** 저점만, 2010-01-01 뒤 10거래일째부터. 저점이 5개 미만이면 그 해 상태 없음.
2. 지표 고르기(434개 전부에서, 사람이 고르지 않음): 저점 '1일 전 자리'의 평균(real)을
   - 날짜를 통째로 옮긴 가짜 200번과 견준 z (|z| ≥ 3),
   - 지수가 비슷하게 움직인 다른 날(1일 전 `PK_등락_5d` 자리가 같은 10칸, 저점 10일 전~당일 제외)에서 뽑은 가짜 200번과 견준 zm (|zm| ≥ 2.5),
   - 저점 1일 전에 값이 있던 비율 ≥ 70%, cut 직전 250일에 값이 있던 비율 ≥ 90%,
   - (real ≥ 55 이고 다른 날 평균보다 높음 → '80 이상' 조건) 또는 (real ≤ 45 이고 더 낮음 → '20 이하' 조건)
   을 모두 채운 지표를 |zm| 큰 순으로, 이미 고른 것과 자리 상관 |0.8| 초과면 건너뛰며 **최대 8개**.
   (원래 코드는 선물 5일 등락 `PF_등락_5d` 로 맞췄다. 여기서는 전환점을 코스피 종가로 잡으므로 `PK_등락_5d` 로 맞춘다.)
3. 점수[t] = 고른 조건(자리 ≥ 80 또는 ≤ 20) 가운데 t일에 켜진 수.
4. 점수 문턱 k = cut 앞 저점의 40% 이상을 '3일 전~당일'에 잡는(그 4일 중 하루라도 점수 ≥ kk) 가장 높은 kk(조건 수 … 2). 없으면 2.
5. 켜짐 구간 2가지: **S5** = 점수 ≥ k 인 날이 최근 5거래일(당일 포함) 안에 있음, **S10** = 최근 10거래일 안.
   해 Y 의 규칙(지표·k)을 Y 년의 날에 적용한다(구간이 전해 말에 걸치면 같은 규칙으로 전해 말 점수를 본다 — 지난 값이라 미래 자료 아님).
- 무작위 씨앗 = C.SEED + Y. 문턱 80/20·40%·3일·8개·z 기준은 turn_signal.py 값 그대로(고르지 않음).

## 2. 방아쇠 (목록·정의 고정, 전체 기간 같은 정의 — 고르지 않음). t = 신호일(장 마감 뒤 확정)
| 번호 | 이름 | 정의 |
|---|---|---|
| T1 | 첫 반등일 | c[t] > c[t−1] 이고 c[t−1] < c[t−2] |
| T2 | 전일 고가 돌파 | c[t] > h[t−1] |
| T3 | 이틀 연속 상승 마감 | c[t] > c[t−1] 이고 c[t−1] > c[t−2] |
| T4 | 장대 양봉 | r[t] ≥ +1.5% (변동폭 맞춤판: r[t] ≥ 1.0 × σ[t]) |
| T5 | 5일선 회복 | c[t] > MA5[t] 이고 c[t−1] ≤ MA5[t−1] (MA5[t] = c[t−4..t] 평균) |
| T6 | 반대매매 정점 통과 | x = `C_반대매매_억`(자료표의 시각 그대로 — 이미 하루 늦춰 들어 있음). 자리(x) ≥ 80 인 날이 나오면 '대기'. 대기 중에 x[t] ≤ 0.7 × max(x[t−5..t−1]) (값 3개 이상) 인 **첫 날**이 방아쇠, 대기 풀림. 대기에 기한은 두지 않는다. 같은 날 두 조건이 다 맞으면 방아쇠로만 친다. 값이 없는 날은 건너뜀 |
| T7 | 외국인 매도 둔화 | 자리(`S_외국인현물_5d`)[t−1] ≤ 20 이고 `S_외국인현물_1d`[t] > 0 이고 `S_외국인현물_1d`[t−1] ≤ 0 (많이 판 상태에서 당일 순매수로 돌아섬) |
| T8 | 변동성 꺾임 | v = `V1_VKOSPI`(없는 날은 `M_VKOSPI`). 자리(v)[t−1] ≥ 80 이고 v[t]/v[t−1] − 1 ≤ −5% |
| T0 | 방아쇠 없음 | 상태 켜짐 구간의 모든 날(견줄 것) |

## 3. 신호와 채점
- 상태+방아쇠: (S5 또는 S10)[t] 이고 방아쇠[t] 인 날 t (Y 년의 날에 Y 년 규칙). 방아쇠만: 2016~2026 의 방아쇠 날 전부(상태를 안 쓰니 전 기간 같은 규칙).
- 채점 4가지: 보유 3·5·10일(t+1 시가 매수 → t+h 종가 매도, 오르면 맞음) + 보유일 없는 채점
  (t+1 시가 기준 +5% 에 −5% 보다 먼저 닿으면 맞음, 같은 날 둘 다면 틀림, 60거래일 안에 둘 다 아니면 뺌 — `C.first_touch(D, 0.05)`. trades 에 hit 칸, exit = 닿은 날).
- 보유일 없는 채점 후보에는 `base_y`(거래일마다 '그 날이 신호일이었다면 같은 닿기 채점으로 맞았나' 1/0/nan, 길이 D.n — 기본판은 `C.first_touch(D, 0.05)` 의 y, 변동폭 맞춤판은 ±1.0σ√20 닿기 배열)를 같이 넘겨, 판정이 '같은 해 아무 날'과 가짜 신호를 같은 채점으로 재게 한다(가짓수·격자는 그대로).
- 솎지 않은 모든 신호를 넘긴다(독립 거래 솎기·가짜 시험·2026 넣고 빼기는 sa_judge.py).

## 5. 변동폭 맞춤판 (vol=True — T4 가 부름. 가족·가짓수 같음)
- 전환 저점: zigzag 의 문턱을 날마다 바뀌게 — t일의 전환 크기 = σ[t] × √20 × 1.0 (5% 대신).
- T4 장대 양봉: r[t] ≥ 1.0 × σ[t].
- 보유일 없는 채점: 매수일 e = t+1 의 시가 기준 ±1.0 × σ[e] × √20 (σ[e] 는 t일 종가까지로 계산되므로 t일에 아는 값).
- 그대로 두는 것: 자리 문턱 80/20, T6 의 30%·T8 의 5%(지수 등락이 아니라 반대매매 금액·변동성 지수의 비율이고 자리 조건이 이미 '그때 수준'에 맞춰져 있음), 보유 3·5·10일.
- 후보 id 앞에 `V_`, desc 앞에 `[변동폭 맞춤]`. run.py 의 merge 는 (cands, meta)만 돌려주고 저장하지 않는다.
