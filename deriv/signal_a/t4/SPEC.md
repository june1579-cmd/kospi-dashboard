# T4 변동폭 맞춤 — 미리 정한 시험 목록 (2026-11-24, 돌리기 전에 고정)

## 왜
2026년은 하루 변동폭이 평소의 3~4배다. '지수 위 1.5% 안', '±5% 먼저 닿기', '하루 +1.5%' 같은 고정 문턱은 변동폭이 큰 해와 작은 해에 뜻이 달라진다.
T4 는 **T1·T2·T3 과 똑같은 가족·똑같은 가짓수**를 문턱만 '그때 변동폭'에 맞춰 다시 돌린다. 새 가족을 늘리지 않는다.

## 무엇을 (t1·t2·t3 의 SPEC.md 에 적힌 변동폭 맞춤판 그대로 — 여기서 새로 정하는 것은 없다)
| 원래 줄기 | 바뀌는 문턱 | 그대로인 것 | 가짓수 | 해마다 고르는 절차 |
|---|---|---|---|---|
| T1 위치·사건 규칙 | 콜벽 거리: % → σ 단위(0.5·1.0·1.5·2.0·2.5σ), 수급 확인: '>0' → '직전 250일 표준편차의 0.5배 초과' | 벽 종류·나이·물량 변화·장세·늦춤·첫 신호·보유일·방향, 고르는 절차, 가짜 200번 | 128,640 | 28 |
| T2 상태 → 방아쇠 | 전환점 크기 5% → 직전 60일 σ×√20, 장대 양봉 +1.5% → 1.0σ, 먼저 닿기 ±5% → ±1.0σ√20 | 상태 고르는 법, 방아쇠 8개, 보유 3·5·10일 | 104 | 104 |
| T3 합의·확률 | 맞힐 대상: 'h일 뒤 오름' → '±0.5σ√h 중 위쪽에 먼저 닿음', 벽 거리 띠 1.5%·3% → 1.5σ·3σ | 입력 묶음 2, 모형 3, 문턱 2, 합의 절차 | 2,730 | 51 |
| 합계 | | | **131,474** | **183** |

- σ = 그날까지 직전 60거래일의 코스피 일간 종가 등락 표준편차(미래 자료 아님).
- 판정에서 가짜 신호 시험 보정에 쓰는 가짓수: 해마다 고르는 절차는 183(m_wf), 전체 기간 고정 규칙은 T1 변동폭 맞춤판의 128,640 + 1 + 1(m_fixed).
- 후보 id 는 `t1_V_…`·`t2_V_…`·`t3_V_…`, 설명 앞에 '[변동폭 맞춤]'.
- 보유일 없는 채점(먼저 닿기) 후보는 '같은 해 아무 날'도 같은 닿기 방식으로 잰다(base_y).

## 계산
조각 15개 = T1 7(벽 종류 하나씩) + T2 1 + T3 7(모형 6 + 합의 1). 조각당 1~5분, 합치기 5~25분(T1 의 가짜 200번 포함) 어림(실행기 4코어).
합치기는 줄기마다 따로 프로세스를 띄워 그 줄기의 merge(vol=True) 를 부른 뒤 모은다. 조각이 빠지면 그 줄기 쪽에서 parts_failed 로 적힌다.

## 안 넣은 것 (아쉬운 줄기 보고용 — 자동으로 돌리지 않음)

- 변동폭이 큰 날에만 켜는 신호처럼 변동폭 자체를 조건으로 넣기
- T5(하락) 가족의 변동폭 맞춤판
- t1~t3 각 SPEC 의 '안 넣은 것'은 변동폭 맞춤판에도 그대로 안 넣음
