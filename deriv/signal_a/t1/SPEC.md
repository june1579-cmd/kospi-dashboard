## 2. 가족 (차원 10개의 곱)
| 차원 | 값 |
|---|---|
| 벽 종류 7 | F0, F1, F2, F3, Q, ALL, K2 |
| 거리 5 | 벽이 지수 위 0 초과 ~ b% 이내, b = 0.5, 1.0, 1.5, 2.0, 3.0 (**변동폭 맞춤판**: 0 초과 ~ sσ 이내, s = 0.5, 1.0, 1.5, 2.0, 2.5) |
| 벽 나이 3 | 상관없음 / 새 벽(wall_new = 1) / 새 벽 아님(wall_new = 0) |
| 벽 물량 변화 4 | 상관없음 / 5일 증가(chg5 > 0) / 1일 증가(chg1 > 0) / 5일 감소(chg5 < 0) |
| 수급 확인 4 | 없음 / 외국인 선물 3일 누적 > 0 / 외국인 현물 3일 누적 > 0 / 둘 다 (**변동폭 맞춤판**: '> 0' 대신 '3일 합 > 0.5 × 직전 250일(어제까지, 120일 이상 있을 때) 3일 합의 표준편차') |
| 장세 3 | 상관없음 / 코스피 종가 > 60일선 / 종가 < 60일선 |
| 늦춤 2 | 0 (조건일 다음 날 시가 매수) / 1 (하루 쉬고 그다음 날 시가 매수) |
| 첫 신호 2 | 전부 / 직전 5거래일 안에 같은 조건이 없던 첫날만 (D.first_only(mask, 5)) |
| 보유일 4 | 1, 3, 5, 10 |
| 방향 2 | 오름(+1) / 내림(−1) |

**K2 의 정의**: F0·F1·F2·ALL 가운데 둘 이상이 같은 날 `wall_new = 1` 인 날.
- 거리 = 그날 새 벽이 된 결제월들 가운데 가장 가까운 벽의 거리(그 값이 0 초과 ~ b 이내).
- 벽 나이 = 정의상 '새 벽' 하나뿐(상관없음·새 벽 아님은 같은 것/빈 것이라 뺀다).
- 벽 물량 변화 = 그날 새 벽이 된 F0·F1·F2(ALL 은 변화 열이 없음) 가운데 하나라도 그 조건(chg5 > 0 / chg1 > 0 / chg5 < 0)을 채움.
- 연구소 A4yu_K2 와 다른 점: 연구소는 '띠 안에 든 새 벽이 둘 이상', 여기는 '새 벽 둘 이상 + 가장 가까운 새 벽이 띠 안'.

## 3. 매매·독립 거래
- 조건일 t(장 마감 뒤 앎) → 늦춤 d → 신호일 t+d → t+d+1 시가 매수 → t+d+h 종가 매도. 코스피 지수. 적중 = 방향 × 수익 > 0.
- 독립 거래 = 앞 거래 청산일 이후(같은 날 포함)의 신호만(D.thin_pos 와 같음).

## 4. 해마다 고르는 절차 (wf) — C.wf_splits(): 2016~2026
해 Y 마다, **청산일이 Y-01-01 전인 독립 거래만**(2010~)으로 규칙별 n(거래 수)·적중을 계산해 고른다. 방향별로 따로.
- 최소 거래 수 n_min(Y) = max(12, round(35 × (Y − 2010) ÷ 17)) → 2016년 12 … 2026년 33.
- 고르는 꼴 2: **통과 꼴** = n ≥ n_min 그리고 적중 ≥ 85% / **관찰 꼴** = n ≥ n_min 그리고 적중 ≥ 80%.
- 쓰는 수 4: 고른 것 가운데 윌슨 하한(단측 95%) 상위 **1개 / 5개 / 20개 / 전부** (같으면 n 많은 것, 그다음 규칙 번호 순).
- 신호 만드는 법 2:
  - **하나라도**: 쓰는 규칙 중 하나라도 신호일이 그날인 날 → 그 규칙의 보유일로 거래. 같은 날 여럿이면 윌슨 하한이 가장 높은 규칙의 것.
  - **합의**: 쓰는 규칙의 20% 이상(올림, **최소 2개** — 1개면 '하나라도'와 같아지므로)이 같은 날 신호인 날 → 보유일은 그 규칙들 보유일의 가운뎃값(.5 는 올림). 상위 1개에는 해당 없음.
- 방향 2: 오름 / 내림.
- 신호일(= 조건일 + 늦춤)이 Y 년인 것만 그 해 거래로 삼아 2016~2026 을 이어 붙인다(kind='wf', 솎기는 판정이 함).

**wf 절차 수 m_wf = 꼴 2 × (쓰는 수 4 × 만드는 법 2 − 1[상위 1개·합의]) × 방향 2 = 2 × 7 × 2 = 28.**
id: `WF_<goal|watch>_<top1|top5|top20|all>_<any|cons>_<up|dn>` (변동폭 맞춤판은 앞에 `V_`).

## 5. 같은 절차를 가짜 신호로 (200번)
- 가짜 = 수익률 줄(보유일 1~10일 전부 함께)을 **해 안에서만 통째로 돌림**(해마다 1 ~ 그 해 거래일 수 − 1 사이 무작위 회전). 씨앗 C.SEED + 번호.
- 규칙의 독립 거래 위치는 수익과 무관하므로 그대로 두고, 가짜 수익으로 n·적중 → 고르기 → 그 해 채점을 똑같이 다시 한다.
- 표: 절차별 실제 다음 해 적중과 가짜 200번의 분포(평균·5%·50%·95%), 가짜가 실제 이상인 비율 → `out/tables/wf_fake.csv`, summary.md.
- 덤(같은 계산에서 나옴): 해마다 '고른 규칙 수' 실제 대 가짜(`wf_sel_counts.csv`), 전체 기간 35건 이상·85%(80%) 이상 규칙 수 실제 대 가짜(`insample_counts.csv`).

## 8. 계산 설계·시간
- 조각 7개 = 벽 종류 하나씩(F0, F1, F2, F3, Q, ALL, K2). 조각은 (조건 묶음 × 늦춤 × 보유일)별 독립 거래의 신호 위치만 작게 넘긴다(수익은 보지 않음).
- merge: 해마다 n·k 누적표 → 실제 고르기·채점 → 가짜 200번(joblib 4코어) → 표.
- `--quick`: 벽 2개(Q·K2)·보유일 2개(3·5)·가짜 5번, 조각 1 하나로 끝.
- 예상 시간(실행기 4코어, quick 시험에서 어림): 아래 9절.

## 9. 예상 시간 (quick 시험 뒤 어림만 적음 — 가족·문턱은 그대로)
- quick 시험(2코어 컴퓨터): 조각 1 = 1초, merge(규칙 15,360개·가짜 5번) = 2초, 판정(--iters 100) = 6초.

  **merge 3~15분**(가짜 200번 × 한 번 1~3초 ÷ 4코어 + 표). 메모리 1GB 미만.
- 변동폭 맞춤판(vol=True)은 σ 띠가 넓어 신호일이 2~3배 많다 → 조각 1~2분, merge 5~20분 어림.
- merge(parts, vol, quick, out_dir=None): out_dir 을 주면 그 아래 tables/·summary.md 를 쓴다(vol 이면 파일 이름 앞 `V_`). 요약 글은 meta['summary_md'] 에도 들어 있다.
