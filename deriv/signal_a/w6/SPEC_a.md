### 2.1 내림 방향(t2x_down)
- 꼭지 상태: 원래 상태 고르기와 같은 방식을 **전환 고점**(고점에서 5% 이상 내리면 그 고점, cut 전에 확정된 것만)에 적용. 고점 1일 전 자리 평균이 가짜 2종(날짜 옮김·지수 움직임 맞춤)보다 뚜렷한 지표 최대 8개, 점수 문턱 = 고점의 40% 를 3일 전~당일에 잡는 가장 높은 값. 씨앗 C.SEED + 해.
- 하락 방아쇠 7개(오름 방아쇠의 거울 꼴, 정의 고정): D1 첫 반락일(c[t] < c[t−1] 이고 c[t−1] > c[t−2]) · D2 전일 저가 이탈(c[t] < l[t−1]) · D3 이틀 연속 하락 마감 · D4 장대 음봉(r[t] ≤ −1.5%) ·
  D5 5일선 이탈(c[t] < MA5[t] 이고 c[t−1] ≥ MA5[t−1]) · D7 외국인 매수 둔화(자리(`S_외국인현물_5d`)[t−1] ≥ 80 이고 `S_외국인현물_1d`[t] < 0 이고 [t−1] ≥ 0) · D8 변동성 되오름(자리(VKOSPI)[t−1] ≤ 20 이고 하루 +5% 이상).
  T6(반대매매)는 거울 꼴이 없어 뺀다.
- 채점: 다음 날 시가에 팔았다고 보고 3·5·10일째 종가에 되삼(내리면 맞음), 보유일 없는 채점 = 시가 기준 −5% 에 +5% 보다 먼저 닿으면 맞음(같은 날 둘 다면 −5% 먼저로 침 — T5 와 같음). direction = −1.

### 3.3 새 채점 2개
- **t3**: 다음 날 시가 기준 −3% 에 +3% 보다 먼저 닿으면 맞음(`C.first_touch(D, 0.03)` 의 y == 0, 60거래일 안에 둘 다 없으면 뺌).
- **ts**(변동폭 맞춤): 매수일 e = t+1 의 시가 기준 ±1.0 × σ[e] × √20 (σ = 직전 60일 일간 등락 표준편차, 당일 제외 — T2 변동폭 맞춤판과 같은 식) 가운데 −쪽에 먼저 닿으면 맞음.
- 둘 다 trades 에 hit 칸, 후보에 `base_y`(그 날이 신호일이었다면 같은 채점으로 맞았나) 를 같이 넘긴다.

### 3.4 짝을 해마다 고르는 절차 (t5x_pairwf)
해 Y·채점마다: 학습 구간(2010~, 청산일 < Y-01-01)에서 703쌍 각각의 독립 거래 n·내림 적중 p, 같은 구간 아무 날 적중 b → **n ≥ 20 이고 p ≥ b + 10%p** 인 짝을 고른다(절차 B 와 같은 기준).
- **P_any1** = 고른 짝 가운데 하나라도 켜진 날(Y 년), **P_top5** = 고른 짝 가운데 (p − b) 가 큰 순 5개(같으면 n 많은 것 → 짝 번호 순) 중 하나라도 켜진 날. × 채점 4 = 8개.

### 3.5 확률 모형 (t5x_model) — 인버스 연구·T3 과 같은 학습 함수 꼴, 입력만 T5 묶음
- 입력 38개: 자리 조건 30개는 그 자리 값(0~1, 켜지는 쪽이 1 에 가깝게 — f1·f3·f5 는 선물·현물 두 자리 중 작은 값), 자리 아닌 8개는 0/1.
- 대상: 채점 4가지 각각 '내림 맞음'(h3·h5·h10 = 그날 수익 < 0, t5 = −5% 먼저).
- 해 Y(2013~2026)마다 그 전 자료(2010~, 청산이 Y 첫 거래일 전인 날, 400일 이상)로 다시 학습 — 나무 모형(HistGradientBoosting: 200회·학습률 0.05·깊이 3·잎 40·l2 1.0·random_state 7)과 선형 모형(로지스틱 C = 0.05)의 평균. 설정은 t3/run.py·uni_model.py 값 그대로(고르지 않음).
- 문턱 2: 내릴 확률이 **그 전 해들의 표본 밖 예측(200개 이상)의 상위 10% 선 / 상위 5% 선** 이상인 날(2016~2026). 2 × 4 = 8개.
