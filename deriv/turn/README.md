# 전환점 연구 (deriv/turn)

2026-11-23 사용자 지시: "무작정 훑지 말고, 하락에서 상승으로·상승에서 하락으로 돌아설 때 공통으로 일어나는 지수·수급의 변화를 찾고, 어떤 조합이 가장 많이, 높은 확률로 찾아내는지 본다."

| 파일 | 하는 일 |
|---|---|
| `turn_probe.py` | 전환점을 정하고(저점에서 5%·8% 반등 / 고점에서 5%·8% 하락), 전환 때의 공통점(조건 1개)과 전환점을 찾아내는 조합(조건 1~3개 전부)을 센다. `--fit 2016`…`2026` = 그 해 이전 자료로 고르고 그 해에 채점, `--fit FULL` = 전체 기간 |
| `turn_report.py` | 맞춤별 결과를 모아 `out/report.md`·`out/summary.json` |

- 계산 핵심은 `deriv/combo/combo.c`(검산 `deriv/combo/test_core.py`)를 그대로 쓴다. 자료·조건은 통합 예측 연구소 자료표와 같다.
- 실행: `deriv/turn/trigger.txt` push → GitHub `turn-probe`(맞춤 12개 동시). KRX 로그인 없음.
- 전환점은 지나고 나서야 확정되는 표지다. 그래서 해마다 고를 때는 그 해 시작 전 가격으로만 전환점을 정한다.
