# 전환점 연구 (deriv/turn)

2026-11-23 사용자 지시: "무작정 훑지 말고, 하락에서 상승으로·상승에서 하락으로 돌아설 때 공통으로 일어나는 지수·수급의 변화를 찾고, 어떤 조합이 가장 많이, 높은 확률로 찾아내고 성과를 내는지 본다."

| 파일 | 하는 일 |
|---|---|
| `turn_probe.py` | 전환점을 정하고(저점에서 5%·8% 반등 / 고점에서 5%·8% 하락), ① 전환 때의 공통점(조건 1개, 묶음별) ② 많이 내린(오른) 날 가운데 진짜 전환만 가른 조건 ③ 전환점을 찾아내는 조합(조건 1~3개 전부)을 센다. `--fit 2016`…`2026` = 그 해 이전 자료로 고르고 그 해에 채점, `--fit FULL` = 전체 기간 |
| `turn_report.py` | 맞춤별 결과를 모아 `out/report.md`·`out/summary.json` |

정한 것
- 전환 구간: **미리** = 전환점 3일 전~당일, **직후** = 전환점 다음 날~3일 뒤. 신호는 5거래일 간격으로 솎아 센다.
- 조건 묶음: 전부 / 지수만(코스피·선물 자기 가격) / 수급만(투자자별 매매 + 신용·미수·대주) / 선물·옵션 구조만 / 지수 빼고 전부. 묶음마다 따로 전부 훑는다.
- 고르는 규칙: 구간 안 50%·8개, 35%·8개, 25%·10개, 35%·8개 + 그 뒤 10일 방향 65%(또는 80%).
- 상위 표 두 가지: "가장 많이 찾은 조합"(구간 안 35% 이상인 것 가운데 찾은 수 순), "전환점도 찾고 그 뒤 10일 방향도 가장 좋은 조합". 켜진 날이 똑같은 조합은 하나로 친다.
- 전환점은 지나고 나서야 확정되는 표지다. 그래서 해마다 고를 때는 그 해 시작 전 가격으로만 전환점을 정한다.

- 계산 핵심은 `deriv/combo/combo.c`(검산 `deriv/combo/test_core.py` — 실행 때마다 먼저 돈다). 상위 표에 든 조합은 파이썬으로 다시 세어 핵심 계산과 같은지 확인한다(다르면 멈춘다).
