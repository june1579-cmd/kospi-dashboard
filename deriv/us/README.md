# 미국·한국 선물옵션 연동 연구 (갈래 C, 2026-11-22~)

질문: 미국 선물·옵션·변동성·포지션 자료가 다음 한국 거래일 시가 뒤의 코스피200 선물 방향을 미리 알려 주는가.

| 파일 | 하는 일 |
|---|---|
| us_collect.py | 미국 공개 자료 수집(야후 일봉·1시간 봉, Cboe 지수·풋콜 비율, CFTC 포지션, 야후 SPY·QQQ 옵션 체인). KRX 로그인 없음 |
| us_features.py | 한국 거래일에 맞춘 지표(다음 한국 개장 전에 나온 미국 값만) + 3년 백분위 |
| us_study.py | 에이전트 A11 — 미리 정한 지표×문턱×방향×보유 기간 후보, 갭/장중 분해표 |
| us_dash.py | 대시보드 자료 out/dash.json (옵션 구조·감마 추정·검증 요약) |

- 실행: `deriv/us/trigger.txt` 를 바꿔 push → 워크플로 `usk` (첫 줄 all / collect / study). 판정은 연구소 A8(양방향 교차 검증)·A10(반증)을 그대로 씀(LAB_TRACK=c → round_c.json · out_c · state_c).
- 받지 않는 것: SqueezeMetrics GEX·DIX(약관이 자동 수집 금지), Cboe 지연 시세 옵션 체인(GitHub 에서 403). 미국 행사가별 자료는 과거가 없어 `data/us_walls_hist.csv` 에 날마다 쌓음.
- 시각 규칙·늦춤: us_features.py 머리말.
- 라운드 1 결과(2026-11-22): 후보 2,508 · 앞 선별 0 · 뒤 선별 4 · 양방향 통과 0. 미국 밤사이 등락과 한국 시가 갭 상관 0.55, 시가 뒤 장중 상관 −0.08.
