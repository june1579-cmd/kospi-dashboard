# 조건 조합 전부 훑기 검증 (deriv/combo)

2026-11-23 사용자 요청("모든 조합을 대입하려면 얼마나 걸리나 → 그 답을 검증하고 무엇이 옳은 방법인지 확인")으로 만든 **일회성 검증 계산**이다. 신호·기준·다른 갈래 파일은 건드리지 않는다.

| 파일 | 하는 일 |
|---|---|
| `combo.c` | 조건 1~4개 조합을 하나도 빼지 않고 세는 핵심 계산(C, 여러 코어). 신호일 35일 미만인 조합은 통과할 수 없으므로 그 확장만 건너뛴다 |
| `combo_core.py` | 위 계산을 부르는 껍데기 + 느리지만 뻔한 파이썬 계산(검산용) |
| `test_core.py` | 작은 무작위 문제에서 두 계산의 숫자가 모두 같은지 확인 |
| `combo_probe.py` | 한 번 실행 = 한 '맞춤'. `--fit 2016`…`2026` = 그 해 이전 자료로 고르고 그 해에 채점, `--fit FULL` = 전체 기간에서 통과 숫자 세기 |
| `combo_report.py` | 맞춤별 결과를 모아 `out/report.md`·`out/summary.json` |

실행: `deriv/combo/trigger.txt` 를 push 하면 GitHub `combo-probe` 워크플로가 자료표를 만들고 맞춤 12개를 동시에 돌린다. KRX 로그인 없음.
