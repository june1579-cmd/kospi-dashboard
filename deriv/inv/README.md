| 단계 | 파일 | 하는 일 |
|---|---|---|
| I1 인버스 가격 | `inv_prices.py` | KODEX 인버스(1배)·200선물인버스2X(2배)의 실제 일별 시세를 받아(네이버 금융 공개 자료, 로그인 없음) 선물 수익과 맞는지 점검. 못 받은 날은 선물 수익으로 계산 |

| 총괄 | `AGENT.md` | 예약 에이전트가 결과를 읽고 다음 실험을 정한다(기준은 못 바꿈) |
