- KRX Open API 에는 공매도 항목이 없고, 증권사 API 는 체결량만 준다(잔고 없음).

조회를 아끼는 규칙

- 할 일이 없으면 pykrx 를 불러오지 않아 KRX 로그인도 하지 않음
- 잔고는 거래일 T 의 값이 T+2 거래일에 공개 — 최근 3거래일의 빈 응답은 '아직 공개 전'으로 보고 세지 않음
