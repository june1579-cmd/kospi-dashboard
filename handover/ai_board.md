## 5. 끝내기 전 점검표
- [ ] 뉴스 검색을 마지막 Claude 실행 뒤로 잡았고 status.changed 의 큰 변화는 원인부터 찾았다.
- [ ] 새 행마다 출처를 직접 열었다. 전달 보도를 2곳으로 세지 않았다. 1곳 보도는 '중요'일 때만, 표기를 다 넣었다.
- [ ] news 8행 이하·새 행 3건 이하. 7일 된 행·이어 내릴 행을 정했고 run.changed 에 "+n건·고침 n건·내림 n건".
- [ ] 오늘 코스피 마감(3% 미만이면 코스피 행 후속)과 당국 소식(당국 행 후속)을 덧붙였다. policy_stage cur_text 에 오늘 줄("… 없음(HH시 MM분 기준)")이 있다.
- [ ] 일정 결과가 나왔으면 events·macro·뉴스를 함께. 저녁이면 원/달러 주간 종가(2곳).
- [ ] status.stale 을 봤다. 못 구한 값은 넣지 않고 unverified. GitHub 몫 숫자를 내 손으로 넣지 않았다.
- [ ] 화면 글 음수 `−`, JSON 숫자 `-`, %와 %p 구분. request 에 경계값·확률·stage·rank 없음.
- [ ] marker 일치·ok 뒤에만 대시보드에 올렸고 자산 하나의 sha256 대조, uploaded.json 커밋. 알림은 조건이 맞을 때만, 보고 끝에 "투자 권유 아님".

## 6. 하지 말 것
- `docs/ai/data/*.json` 을 직접 고치지 않는다. 저장소 안의 코드를 실행하지 않는다.
- 숫자 측정값 10개·거시 5개를 웹 검색으로 다시 찾지 않는다. SOX 종가를 ETF 값으로 대신 적지 않는다. 기억·추정·보간 금지.
