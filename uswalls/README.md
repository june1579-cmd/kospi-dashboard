## 추정 방법
- 야후 옵션 체인(만기 45일 안): 미결제약정 = 직전 장 **전** 마감 포지션(OCC 공식), 거래량 = 직전 장.
- 추정 미결제 = 공식 미결제 + k × 거래량(0 아래면 0). k 는 날마다 "전날 거래량 → 오늘 공식 미결제 변화"로 콜·풋 따로 맞추고 최근 5번 가운데값을 쓴다(기록 없으면 0.35).
- 벽 = 현재가 위(콜)·아래(풋)에서 감마×미결제가 가장 큰 행사가(현재가 ±10%). "전날 확정" 벽은 같은 현재가로 계산한다(가격 효과를 빼고 포지션 변화만).
- 정확도: 어제 추정한 벽 ↔ 오늘 공식 미결제로 계산한 벽(어제 현재가 기준).
- 신규·청산은 거래량으로 구분할 수 없어 추정치다. 원자료는 추정으로 채우지 않는다.

## 알아 둘 것(고칠 때)
- **야후는 뉴욕 새벽~아침(한국 오후~저녁)에 미결제를 0 으로 비운다.** 그 시간대에 돌리면 `walls.py` 가 "비어 있음"으로 실패하는 것이 정상이다(손으로 시험할 때 주의). 정규 실행(06:47 KST = 뉴욕 16:47)에는 채워져 있다.
- 미국 휴장 다음 날 아침은 "새 미국 장 거래 없음" 글을 보낸다(실패 아님).
- 같은 날 다시 돌리면(감시의 재시도) 같은 장을 다시 계산한다(기록이 겹치지 않음).
- 첫 기록(2026-11-23 장)은 연구 가지의 기존 스냅숏으로 만들었고 비율은 기본값 0.35 다.
- 공개 시각 측정에서 CME(ES 옵션 일일 보고서)는 GitHub 에서 403 으로 막혀 뺐다.
- SPX(지수 옵션)는 무료 자료가 없어 다루지 않는다. Cboe 지연 시세는 Cboe 가 자동 수집을 금지해 쓰지 않는다.
