한국투자증권 과거 1분봉 수집기 — 사용법
==========================================

[처음 한 번]
1. 이 폴더의 .env 파일을 메모장으로 엽니다. (오른쪽 클릭 → 연결 프로그램 → 메모장)
2. KIS_REAL_APP_KEY, KIS_REAL_APP_SECRET, GITHUB_TOKEN 의 = 뒤에 값을 붙여 넣고 저장합니다.
3. start_collector.bat 을 더블클릭합니다.
   - 파이썬이 없으면 자동으로 설치합니다.
   - 설정 점검이 끝나면 카카오톡으로 "PC 설정 점검 완료" 알림이 옵니다.
   - "Started" 가 나오면 창을 닫아도 됩니다. 수집은 화면 없이 뒤에서 돕니다.

[그다음부터는 할 일 없음]
- 인터넷이 끊겨도, PC를 재부팅해도 10분 안에 자동으로 이어 받습니다.
- PC 전원과 절전 모드(잠자기 끄기)만 신경 써 주세요.
- 매일 아침 06:50 카카오톡으로 진행 상황이 옵니다.
- 다 받으면 "분봉 수집 완료" 알림이 오고, 자동 재시작 등록도 스스로 풉니다.

[멈추고 싶을 때]
- stop_collector.bat 더블클릭. 받은 자료는 그대로 남습니다.
- 다시 시작하려면 start_collector.bat 더블클릭 → 받은 곳 다음부터 이어 받습니다.

[폴더 안의 것]
- data\futures_day, data\futures_night : 코스피200 선물 주간·야간 1분봉 (날짜별 파일)
- data\krx  : 주식·ETF KRX 1분봉 (날짜별 파일, 모든 종목이 한 파일에)
- data\un   : NXT 거래 종목의 통합(KRX+NXT) 1분봉
- data\parts : 받는 중인 날짜의 조각 파일 (그날이 끝나면 합쳐짐)
- state\status.json : 지금 진행 상황   / logs\collector.log : 기록
- state\progress.db : 받은 종목·날짜 목록 (지우면 처음부터 다시 받습니다 — 지우지 마세요)

[참고]
- 받는 순서: 선물 1년치 → 주식 전 종목, 가장 오래된 날짜부터.
- 매일 09:05~09:15 에는 잠시 쉽니다. (GitHub 에서 호출 한도를 재는 시간)
- 같은 한국투자 API 키로 다른 프로그램을 동시에 돌리면 둘 다 느려집니다.
