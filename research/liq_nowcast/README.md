# 반대매매 당일 예정치 — 오차 줄이기 시험 (liq-nowcast 가지, 연구용)

금투협 미수 반대매매(기준일 T)는 다음 거래일 15시쯤 공개된다. T일 저녁 20시에 알 수 있는 값만으로 "T일 반대매매 예정치"를 만들 때
오차를 얼마나 줄일 수 있는지 본다. main·대시보드는 건드리지 않는다. 비밀값(KRX·Kakao·API 키)을 쓰지 않는다.

| 파일 | 하는 일 |
|---|---|
| `fetch_public.py` | 공개 자료 수집(네이버 금융 일봉 차트, 로그인 없음): 코스닥 지수, 현재 상장 종목 일봉 → 하루 단위 집계(`data/`) |
| `features.py` | 입력 만들기. 행 T = T일 20시에 알 수 있는 값만(금투협은 기준일 T-1 까지) |
| `leak_check.py` | 미래 자료 섞임 점검(잘라 보기·오염시켜 보기·점검기 확인) → `out/leak_check.txt` |
| `run_experiments.py` | 걷기 검증 시험(입력 묶음 × 모형 × 목표 × 최근 가중 × 섞기 × 범위) → `out/` |
| `trigger.txt` | 고쳐서 push 하면 GitHub Actions(`liq-nowcast`)가 돈다. 첫 줄 all / run / fetch |

결과: `out/summary.md`(요약), `results_point.csv`(모든 설정), `results_interval.csv`(범위), `ablation.csv`(입력 묶음 효과), `by_year.csv`, `preds.csv`(날짜별 예정치·범위), `leak_check.txt`.

규칙: 해마다(또는 달마다) 그 전 자료로만 학습 · 설정은 2019~2025 로만 고르고 2026 은 확인용 · 난수 고정 · 오차 = (예정치 ÷ 실제 − 1) × 100.

한계: 종목 집계는 "지금 상장된 종목"만으로 만든다(과거 상장폐지 종목 빠짐). 네이버 일봉은 가격만 수정주가라 거래대금 가중 값(`vw_`)은 액면분할·무상증자 이전 구간에서 작게 잡힌다.
그래서 결과는 "종목 자료 없이"와 "전체"를 따로 적는다. 코스닥 개인 순매수(2019~)는 공개 경로로 받지 못해 쓰지 않았다(확인 불가).
